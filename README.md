# System Runtimes Installer

## Download and extract the release
1. Open the **Releases** page for this repository.
2. Download the **latest release** ZIP file.
3. Right‑click the ZIP and choose **Extract All…** (or use 7‑Zip/WinRAR).
4. Open the extracted folder.

## Run the installer
1. **Right‑click** `install_all.bat` and choose **Run as administrator**.
2. Wait for all installers to finish.

## Notes
- Keep all installer `.exe` files in the same folder as `install_all.bat`.
- The batch file runs installers one‑by‑one and reports any failures.
